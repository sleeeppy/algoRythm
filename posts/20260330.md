랜덤 마라톤이라는 기능이 있어서 한번 완주 해봤다 마지막 문제 나한테는 너무 어려웠다. 
이게 정해가 맞는건지도 잘 모르겠고 12진수가 너무 생소한데 직접 진수를 구현하려고 하니 너무 당황스러웠다…

각 자리 문자열 구하기{gray}(12진수 변환 함수 구현하기){/} → 문자열 index 참조해 foreach(char) 돌려서 각 자리 합 구하기 → 조건 부합시, List에 넣어서 출력

위처럼 구현하려고 했으나 일단 12진수 변환 함수 `ToDuodecimal()` 만드는 것부터 너무 힘들었다. 
그 뒤에는 각 자리 합을 구현하는데 아래처럼 `radix == 12`만 예외 처리 하고 합 구하는 코드는 최대한 재활용하려 했으나, 아 맞다 `radix == 16`도 문자열 처리 해줘야 한다는 걸 뒤늦게 알아 `||` 해줬다.

`Convert.ToInt32(c.ToString(), radix)`는 2, 8, 16진수에 대해서만 변환해주기 때문에 오히려 10진수만 예외 처리해주면 됐다.

`switch...case` 로 구현 하려 했으나 너무 길어져서 찾아봤더니 ASC를 이용하는 방법이 있었다.
만약 현재 문자 `c`가 `'B'(66)`라면, 여기서 `'A'(65)`를 빼면 `'B' - 'A'`  =>  `66 - 65 = 1`
위에서 계산한 값은 `'A'`를 0으로 맞춘 값이기 때문에, 실제 진법의 값으로 만들려면 **10**을 더해줘야 한다.

`sum += Convert.ToInt32(c);` 치명적인 실수. 여기서 c 넣으면 ASC 값 들어간다.
→ `sum += Convert.ToInt32(c.ToString());`

- `c == Convert.ToChar("A")` → `c == 'A'` {gray}아..  기억해두고 써먹자{/}

```C#
namespace sleeeppy;

public class Program
{
    public static void Main()
    {
        int n = 1000;
        List<int> ansList = new List<int>();
        while (n <= 9999)
        {
            string decN = n.ToString();
            string duoN = ToDuodecimal(n);
            string hexN = Microsoft.VisualBasic.Conversion.Hex(n);

            int decSum = GetDigitSum(decN, 10);
            int duoSum = GetDigitSum(duoN, 12);
            int hexSum = GetDigitSum(hexN, 16);
            
            if ((hexSum == decSum) && (duoSum == decSum) && (hexSum == duoSum))
                ansList.Add(n);
            n++;
        }
        
        foreach (int i in ansList)
            Console.WriteLine(i);
    }

    public static string ToDuodecimal(int n)
    {
        if (n == 0) return "0";

        string result = "";
        string chars = "0123456789AB";

        while (n > 0)
        {
            result = chars[n % 12] + result;
            n /= 12;
        }

        return result;
    }

    public static int GetDigitSum(string n, int radix)
    {
        int sum = 0;
        foreach (char c in n)
        {
            if (radix == 12 ||  radix == 16)
            {
                // switch case ... 대신
                // -> ASC 차이 이용
                if (c >= 'A' && c <= 'F')
                    // A = 10부터 시작이니 +10
                    sum += (c - 'A' + 10);
                else
                    // 여기서 c.ToString 안 하면 ASC 들어감
                    sum += Convert.ToInt32(c.ToString());
            }
            else // 10진수
            {
                // 여기서 c.ToString 안 하면 ASC 들어감
                sum += Convert.ToInt32(c.ToString());
            }
        }
        return sum;
    }
}
```

이렇게 다 풀고나서 찾아봤더니 엄청 편한 방법이 있었다.
생각해보니 각 자리 수의 합을 구할 때도 A=B, B=C ⇒ A=C를 이용해 두 가지만 판단하면 됐다.

어쨌든, `GetDigitSum()` 이 말도 안되게 편해졌다. 각 자리를 진수{gray}(radix){/}로 나눠버리는 것이다.
이러면 따로 A = 10, B = 11 … 를 처리하지 않아도 될 뿐더러, 12진수 변환 함수를 구현할 필요도 없다.

```C#
        while (n <= 9999)
        {
            int decSum = GetDigitSum(n, 10);
            int duoSum = GetDigitSum(n, 12);
            int hexSum = GetDigitSum(n, 16);

            if (decSum == duoSum && duoSum == hexSum)
            {
                Console.WriteLine(n);
            }
            n++;
        }
        
    public static int GetDigitSum(int n, int radix)
    {
        int sum = 0;
        while (n > 0)
        {
            // 나머지 = 해당 자리의 숫자값 (A=10, B=11 자동처리)
            sum += n % radix;
            n /= radix;
        }
        return sum;
    }
}
```
