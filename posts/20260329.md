그리디그리디 문제 풀다가 막혀서 알고리즘 분류 보고 그리디 알고리즘 참고해서 풀었다. 아직 갈 길이 멀었다. 알고리즘 너무 어려움 ㅜㅠ 

반복문을 안 쓰고 꼭 풀어보고 싶었는데 거의 1~2시간 정도 비비다가 ㅈㅈ쳐버렸다. 전에 반복문 써야하는 문제인데 패턴 찾아서 푼 적이 있었어서 이번에도 뭔가 될 줄 알고 어떻게든 해보려다가 실패했다.

```Python
n = int(input())
answer = 0

while(n>=0):
    if(n%5 == 0):
	    # 5가 가장 큰 단위의 수
        answer += n//5
        break;
    n-= 3
    answer += 1
else:
    answer = -1

print(answer)
```

```Python
# cost : 960 (500*1 + 100*4 + 50*1 + 10*1)
# answer = 7

cash, cost = map(int, input().split())
n = cash - cost
answer = 0
arr = [500, 100, 50, 10]
for i in arr:
    if(n>=0):
        answer += n // i
        n -= i*(n // i)
    else:
        break

print(answer)
```
