오늘부터 학교 과제는 py, 내가 공부하는 건 cpp로 풀어야겠다. 
근데 과제 푸는데 왜 이렇게 안 풀리지 

이 문제도 며칠 전에 풀었던 <**싱기한 네자리>**와 유사하게 ASC 대신 UTF를 이용하는 문제였다.
문제를 꼼꼼하게 읽지 않아 1을 소수로 해준다는 것도 처리해주지 않았고,
a=1, A=27로 받는다는 걸 생각하지 않고 계속 `ord('a')+1` 만 하고 있었다.

py에 `str.isupper()` 이런 말도 되는 함수가 있길래 이걸로 계속 풀었더니 계속 60%에서 틀렸다.
알고 보니 이 함수는 전체 str이 소문자인지, 대문자인지 구별하는 함수였고 소문자, 대문자가 섞여 들어오면 판별하지 못한다는 걸 너무 늦게 알았다. 딱 봐도 그렇게 생겼는데 생각이 너무 늦었다.

`def GetSum(word: str):` 이것도 오늘 처음 알게 된 문법인데 함수에 들어가는 파라미터에 **type**을 지정해줄 수 있었다. 기존에는 any로 받고 있었기에 이 함수 내에서 word의 자료형을 몰라 `word.isupper()` 같은 함수들이 자동 완성되지 않고 있었다. {gray}(이것 때문에 isupper() 썼으니 모르는게 좋았을지도 모른다.){/}

{bg:default}소수 판별은 소프트웨어적사고에서 배운대로 {/}{bg:default}**2~n-1**{/}{bg:default}까지 다 볼 필요없고 {/}{bg:default}**2~ sqrt(n)**{/}{bg:default}까지만 보면 된다.
다 풀고 나서 찾아보니 {/}`int(math.sqrt(sum)) + 1` → `sum**0.5`{gray}`(sum^1/2)`{/}가 더 효율적이라 한다.

```Python
import math

def GetSum(word: str):
    sum = 0

    for c in range(len(word)):
        if('A' <= word[c] <= 'Z'):
            sum += (ord(word[c]) - ord('A')+27)
        else:
            sum += (ord(word[c]) - ord('a')+1)

    return sum

def IsPrime(sum):

    if sum == 1:
        print("It is a prime word.")
        return

    for i in range(2, int(math.sqrt(sum)) + 1):
        if(sum%i == 0):
            print("It is not a prime word.")
            break
    else:
        print("It is a prime word.")
        
IsPrime(GetSum(input()))
```
