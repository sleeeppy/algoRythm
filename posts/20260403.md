진짜 거의 1년 만에 cpp를 써보았다.

{gray}**(**{/}{gray}총 응시자 수 - 총감독관이 감시할 수 있는 응시자 수*시험장 수) / 부감독관이 감시할 수 있는 응시자 수){/} 
문제를 보자마자 떠오른 생각이다 위처럼 계산하고 예외 처리 몇 개만 해주면 반복문 없이 되겠는데? 생각했지만 계속 근사치는 나오되, 정확한 답이 나오지 않았다. 

이유는 총 응시자 수로 계산할 경우, 총감독관이 감시할 수 있는 인원을 제외한 나머지 응시자 수가 여러 시험장에서 모인 값이 되어버리기 때문이다. 이러면 시험장별로 필요한 부감독관 수를 계산하는 것과 달라진다.

```C++
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    int n, b, c, answer = 0;
    vector<int> arr(n+1);

    cin >> n;

    for(int i = 0; i < n; i++)
        cin >> arr[i];

    cin >> b >> c;


    for (int i = 0; i < n; i++)
    {
        answer++;

        if(arr[i]%c != 0)
            answer += arr[i]/c + 1;
        else
            answer += arr[i]/c;
    }
    
    cout << answer;

    return 0;
}
```

여기까진 어찌저찌 풀었다. 근데 계속 {blue}런타임 에러(1%){/}가 떴다. 예제 케이스는 모두 통과 했는데 입력이 1000000이라 무슨 일이 벌어진 것 같다고 생각했다. 그래도 잘 모르겠어서 구글링을 했다.

먼저 개빡치는 점은 계속 C++23으로 제출했는데 런타임 에러가 계속 떴다. 이유가 안 떠서 원래 안뜨는줄만 알았는데 런타임 에러 이유를 지원하는 게 C++20까지였다. 바로 변경하고 제출했더니 `OutOfBounds` 

질문 게시판에서  [www.acmicpc.net](https://www.acmicpc.net/board/view/129272) <<  이 글의 반례를 입력해보니 입력도 안 끝났는데 에러가 뜨길래 `long long int`로 바꿔줬다. 이제 입력도 잘 받아 온다.

이제 제출했더니 {red}틀렸습니다.(1%){/}  
문득 든 생각인데 음수가 되는 케이스에서 뭔가 이상함을 느꼈다.

```Plain Text
5
1 1 1 1 1
1000000 1000000
```

입력이 이렇게 들어오면 5가 되어야 하지 않나? 바로 음수 처리 하는 부분을 추가해줬다.
`arr[i] -= b > 0` → `(arr[i] -= b) > 0
`이건 말도 안되는 코드였다. 왼쪽처럼 작성해두고 30분 동안 삽질 엄청 했다.

```C++
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    long long int n, b, c, answer = 0;
    vector<int> arr(n+1);

    cin >> n;

    for(int i = 0; i < n; i++)
        cin >> arr[i];

    cin >> b >> c;


    for (int i = 0; i < n; i++)
    {
        answer++;
        if((arr[i] -= b) < 0)
            continue;

        if(arr[i]%c != 0)
            answer += arr[i]/c + 1;
        else
            answer += arr[i]/c;
    }
    
    cout << answer;

    return 0;
}
```
