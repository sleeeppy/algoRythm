이전에 **.append()** 체이닝 된다는거 기억해서 {bg:gray}+ " "{/}처럼 문자열 연산 안하고 전부 **append** 했다.

아래는 나름? 최적화 한다고 한 코드다.

처음엔 행렬 2개 만들어서 다 넣고 result 행렬에 다 넣어서 제출하려 했었지만, 

출력 형식보고 또 반복문 쓸 생각에 끔직해져서 {gray}으앙그냥한번에출력해야겠다{/}하고 행렬도 하나로 합쳐서 row*2로 돌려서 처리했다.

깍으려면 깍을 수 있을거 같긴한데 잘 모르겠우우..

```java
import java.io.*;
import java.util.*;

public class Main {
  public static void main(String[] args) throws Exception {

    String[] s = IO.readln().split(" ");
    int row = Integer.parseInt(s[0]);
    int col = Integer.parseInt(s[1]);

    int[][] matrix = new int[row*2][col];

    for(int i = 0; i < row*2; i++)
    {
      String[] input = IO.readln().split(" ");

      for(int j = 0; j < col; j++)
      {
        matrix[i][j] = Integer.parseInt(input[j]);
      }
    }

    StringBuilder sb = new StringBuilder();

    for(int i = 0; i < row; i++)
    {
      for(int j = 0; j < col; j++)
      {
        sb.append(matrix[i][j] + matrix[i+row][j]).append(" ");
      }
      sb.append("\n");
    }

    IO.print(sb);
  }
}
```
