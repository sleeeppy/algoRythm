수평 수직인게 정해져서 들어오는게 아니네 아이고
어떤게 수평 수직인지 판단해.

{bold:red}그이후로생각이멈춰버렸습니다.{/}
사실 신나는 보카로 크게 틀어놓고 해서 그런거 같긴하지만
저는 이것도 어렵다고 생각해요오...

어쨋든 만나는 점이 `(vx, hy)`일테니깐 그 안에서 검사해주면 됩니다.


```java
import java.io.*;
import java.util.*;

public class Main {
  public static void main(String[] args) throws Exception {

    Scanner sc = new Scanner(System.in);
    int[] point1 = new int[4];
    int[] point2 = new int[4];

    for(int i = 0; i < 4; i++)
      point1[i] = sc.nextInt();
    for(int i = 0; i < 4; i++)
      point2[i] = sc.nextInt();

    if(point1[1] != point1[3])
    {
      int[] temp = point1;
      point1 = point2;
      point2 = temp;
    }

    int hy  = point1[1];
    int hx1 = Math.min(point1[0], point1[2]);
    int hx2 = Math.max(point1[0], point1[2]);

    int vx = point2[0];
    int vy1 = Math.min(point2[1], point2[3]);
    int vy2 = Math.max(point2[1], point2[3]);
    
    // 만나는 점이 (vx, hy)
    if((hx1 <= vx && vx <= hx2) && (vy1 <= hy && hy <= vy2))
      if((hx1 < vx && vx < hx2) && (vy1 < hy && hy < vy2))
        IO.print(1);
      else
        IO.print(2);
    else
      IO.print(0);

  }
}
```
