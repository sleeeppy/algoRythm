저한테는 이게 무한 디버깅 지옥으로 다가왔는데요
계속 OutOfBounds 나길래 뭔가했더니 j 반복문 안에 i 쓰고 있었어요..

그리고 이 문제 아마 힌트 안들었으면 못 풀었을거 같은게
저는 왼쪽부터 당연히 순회할 생각만 했지. 
이게 동시에 일어나야하는 사건이라는걸 몰라서 영향을 미치면 안된다는 사실을 힌트 듣고 알았어요.

예를 들어 7 7일 경우에는 왼쪽 먼저 8이 되고 8이 됨에 따라 다음 것이 6이 되는 것이 아니라,
각각 동시에 일어나서 8 8이 되어야 하는 것이죠. 

그래서 배열을 `arr = result` 했지만 안되더라구요? 
네~ 래퍼런스 변수라서 {bold}터져서없어짐수고하세요{/}
{gray}직접 반복문으로 업데이트 해줬습니다.{/}

```java
import java.io.*;
import java.util.*;

public class Main {
  public static void main(String[] args) throws Exception {
    String[] s = IO.readln().split(" ");
    int n = Integer.parseInt(s[0]);
    int k = Integer.parseInt(s[1]);

    int[] arr = new int[n+2];
    int[] result = new int[n+2];

    String[] input = IO.readln().split(" ");

    for(int i = 0; i < n; i++)
      arr[i+1] = Integer.parseInt(input[i]);

    for(int i = 0; i < k; i++)
    {
      for(int j = 1; j <= n; j++)
      {
        result[j] = arr[j];

        if((arr[j-1] + arr[j+1]) < 3)
          if(arr[j] > 0) result[j] = arr[j]-1;
          
        if((arr[j-1] + arr[j+1]) > 7)
          if(arr[j] > 0) result[j] = arr[j]-1;

        if(3 < (arr[j-1] + arr[j+1]) && (arr[j-1] + arr[j+1]) <= 7) 
          if(arr[j] < 9) result[j] = arr[j]+1;
      }

      for(int j = 1; j <= n; j++)
        arr[j] = result[j];

    }

    StringBuilder sb = new StringBuilder();

    for(int i = 1; i <= n; i++)
      sb.append(result[i] + " ");
    
    IO.println(sb);
  }
}
```
