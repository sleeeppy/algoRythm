시험 기간이라서 시험 끝나고 재개하겠음.. 그래도 문제는 풀거

```Python
c = int(input())
scoreArr = [];

for i in range(c):
    scoreArr = list(map(int, input().split()))
    avg = (sum(scoreArr)-scoreArr[0])/scoreArr[0]
    avgStudent = 0

    for j in range(1, len(scoreArr)):
        if(avg < scoreArr[j]):
            avgStudent += 1
    
    print("{:.3f}%".format((avgStudent / scoreArr[0]) * 100))
```
