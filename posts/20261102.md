이 문제 보자마자 조건 트리거되면 리스트 append해서 넣으면 되겠당
하고 있었지만 Java문법도 모르고 IDE도 없고 Docs도 없었던나는개같이멸망하고말았습니다.

아래 풀이가 정해라는데 이런 부르트포스 풀이 발상이 안돼서 힘들어요

```java
import java.io.*;
import java.util.*;

public class Main {
  public static void main(String[] args) throws Exception {
    String[] s = IO.readln().split(" ");
    int n = Integer.parseInt(s[0]);
    int[] arr = new int[n+2];

    for(int i = 1; i <= n; i++) 
      arr[i] = Integer.parseInt(s[i]);

    int sum = 0;
    int count = 0;

    for(int i = 1; i <= n;)
    {
      int j = i;
      while(j < n && arr[j] <= arr[j+1]) j++;

      if(i == j)
      {
        i++;
        continue;
      }

      count++;

      for(int k = i; k <= j; k++)
        sum += arr[k];

      i = j + 1;

    }

    IO.println(count + " " + sum);

  }
}
```

아래가 문법 공부하고 푼건데 처음 발상이 이 풀이랑 완벽하게 똑같음
생각해보면 모든 문제를 이런식으로 푸는 것 같은데 괜찮으려나..

```java
import java.io.*;
import java.util.*;

public class Main {
  public static void main(String[] args) throws Exception {
        String[] s = IO.readln().split(" ");
        int n = Integer.parseInt(s[0]);
    
        int[] arr = new int[n+1];
        for(int i = 1; i <= n; i++)
          arr[i] = Integer.parseInt(s[i]);
    
        ArrayList<ArrayList<Integer>> list = new ArrayList<>();
        list.add(new ArrayList<>());
        int idx = 0;

        for(int i = 1; i <= n; i++)
        {
            if(arr[i - 1] > arr[i])
            {
                list.add(new ArrayList<>());
                idx++;
            }
            list.get(idx).add(arr[i]);
        }

        int count = 0;
        int sum = 0;

        for(int i = 0; i < list.size(); i++)
        {
            if(list.get(i).size() == 1) continue;

            count++;

            for(int j = 0; j < list.get(i).size(); j++)
            {
                sum += list.get(i).get(j);   
            }
        }

        IO.println(count + " " + sum);
  }
}
```
