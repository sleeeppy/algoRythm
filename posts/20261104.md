`k(1≤k≤99)`
저는 사실 이런 문제도 무서워서 벌벌떨곤 하는데요.
그 이유 중에 하나가 최적화해서 잘 풀고 싶은데 그걸 못하니까 머리가 아픈거같음

이 문제도 다른 변수 안쓰고 반복문 조건에 한번에 넣고 업데이트 해서 i랑 j만 출력하는걸로 하고 싶었지만,
반복문 안에 다 집어넣으려니 머리아파져서 그냥 대충 풀었음...

```java
import java.io.*;
import java.util.*;

public class Main {
  public static void main(String[] args) throws Exception {
    int k = Integer.parseInt(IO.readln());

    for(int i = 1; i <= k; i++)
    {
      int temp = i;
      for(int j = 0; j < i; j++)
      {
        IO.print(temp + " ");
        temp += k-j-1;
      }
      IO.println();
    }
  }
}
```
